# TC10 — Login Customer

## Mục tiêu
Xác nhận tài khoản seed Customer 1 đăng nhập đúng và mật khẩu sai bị từ chối.

## Điều kiện trước
Mở PowerShell tại thư mục gốc; Compose thường 17 container healthy, đã seed. Tài khoản seed trong `docs/SPEC.md` §12.1: `customer1@example.test` / `Customer@123`. Giới hạn login mặc định 5 lần/phút/IP; chạy hai lần dưới đây một lượt, chờ 65 giây nếu vừa chạy Postman TC29.

## Các bước
```powershell
$uri = 'http://localhost:3000/api/v1/auth/login'
$correct = @{ identifier = 'customer1@example.test'; password = 'Customer@123' } | ConvertTo-Json -Compress
$login = Invoke-RestMethod -Method Post -Uri $uri -ContentType 'application/json' -Body $correct
"correct-tokenPresent=$([bool]$login.data.accessToken) tokenType=$($login.data.tokenType)"
$wrong = @{ identifier = 'customer1@example.test'; password = 'Wrong@123' } | ConvertTo-Json -Compress
$bodyFile = Join-Path $env:TEMP 'tc10-wrong-body.json'
$outFile = Join-Path $env:TEMP 'tc10-wrong-response.json'
[System.IO.File]::WriteAllText($bodyFile, $wrong, [System.Text.UTF8Encoding]::new($false))
$code = curl.exe -s -o $outFile -w '%{http_code}' -H 'Content-Type: application/json' --data-binary "@$bodyFile" $uri
"wrong=$code error=$((Get-Content $outFile -Raw | ConvertFrom-Json).error.code)"
Remove-Item -LiteralPath $bodyFile, $outFile
```
Lệnh login đúng giữ token trong biến PowerShell, không in token. Request sai đọc JSON từ file UTF-8 không BOM, tránh lỗi dấu nháy của shell.

## Kết quả mong đợi
Login đúng trả HTTP 200, `accessToken` không rỗng và `tokenType=Bearer`. Login sai trả HTTP 401 `INVALID_CREDENTIALS`; không có token trong response lỗi. Không tạo hay sửa dữ liệu seed.

## Cách chụp minh chứng
Chụp hai dòng `correct-tokenPresent` và `wrong=401`; không chụp giá trị `$login.data.accessToken`. Gợi ý `TC10-login-success-fail.png`.
