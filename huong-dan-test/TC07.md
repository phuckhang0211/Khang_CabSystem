# TC07 — RabbitMQ exchange, queue và binding

## Mục tiêu
Xác nhận exchange `ride.events` cùng ba queue durable có consumer và routing key đúng luồng.

## Điều kiện trước
Mở PowerShell tại thư mục gốc; 17 container healthy. UI tại `http://localhost:15672`, user `cab`; mật khẩu lấy từ `RABBITMQ_DEFAULT_PASS` trong `.env`, không ghi/chụp giá trị.

## Các bước
```powershell
docker compose exec -T rabbitmq rabbitmqctl list_exchanges name type durable | Select-String 'ride.events'
docker compose exec -T rabbitmq rabbitmqctl list_queues name messages consumers
docker compose exec -T rabbitmq rabbitmqctl list_bindings source_name destination_name routing_key | Select-String 'ride.events'
```
Trong UI, mở **Exchanges → ride.events** để xem type `topic`, durable; mở **Queues** xem `booking.q`, `trip.q`, `notify.q`, số consumer và binding. Sau khi chạy flow Postman TC15–TC16, kiểm queue vẫn có consumer và số message chờ về 0: event `booking.offer.created` được Notify consume, `booking.assigned` được Trip/Notify consume.

## Kết quả mong đợi
Exchange `ride.events` là topic durable. `booking.q`, `trip.q`, `notify.q` đều có ít nhất một consumer, bình thường `messages=0`. Binding: `booking.q` nhận `payment.completed`, `payment.failed`, `trip.completed`, `trip.canceled`; `trip.q` nhận `booking.assigned`; `notify.q` nhận `driver.#`, `payment.#`, `booking.#`, `trip.#`.
