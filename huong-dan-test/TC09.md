# TC09 — Đăng ký Customer

## Mục tiêu
Tạo Customer mới qua Gateway, nhận `ACTIVE`, đăng nhập được rồi dọn đúng user/profile vừa tạo.

## Điều kiện trước
Mở PowerShell tại thư mục gốc; Compose thường 17 container healthy, đã seed. Không cần token trước khi đăng ký. Giới hạn login mặc định 5 lần/phút/IP; không login lặp, và chờ ít nhất 65 giây nếu vừa chạy Postman TC29.

## Các bước
```powershell
$stamp = Get-Date -Format 'yyyyMMddHHmmssfff'
$email = "tc09-$stamp@example.test"
$phone = '+8496' + $stamp.Substring($stamp.Length - 8)
$registerBody = @{ email = $email; password = 'Tc09@123'; displayName = 'tc09-customer'; phone = $phone } | ConvertTo-Json -Compress
$registered = Invoke-WebRequest -UseBasicParsing -Method Post -Uri 'http://localhost:3000/api/v1/auth/register' -ContentType 'application/json' -Body $registerBody
$created = $registered.Content | ConvertFrom-Json
$userId = $created.data.userId
$loginBody = @{ identifier = $email; password = 'Tc09@123' } | ConvertTo-Json -Compress
$login = Invoke-RestMethod -Method Post -Uri 'http://localhost:3000/api/v1/auth/login' -ContentType 'application/json' -Body $loginBody
"register=$($registered.StatusCode) status=$($created.data.status) loginTokenPresent=$([bool]$login.data.accessToken)"
"DELETE FROM customer_profiles WHERE user_id = :'uid'::uuid;" | docker compose exec -T customer-db psql -U customer_user -d customer_db -v "uid=$userId" -At
"DELETE FROM users WHERE id = :'uid'::uuid;" | docker compose exec -T auth-db psql -U auth_user -d auth_db -v "uid=$userId" -At
docker compose exec -T auth-db psql -U auth_user -d auth_db -At -c 'SELECT count(*) FROM users'
docker compose exec -T customer-db psql -U customer_user -d customer_db -At -c 'SELECT count(*) FROM customer_profiles'
```
JSON được tạo bằng `ConvertTo-Json` và truyền qua `Invoke-WebRequest`, không cần escape JSON inline. Hai lệnh dọn dùng đúng `userId` trả từ API, quote bằng biến `psql`; không xóa UUID seed. Không commit email, mật khẩu hoặc token thử nghiệm.

## Kết quả mong đợi
Đăng ký trả HTTP 201 và `status=ACTIVE`; login trả `accessToken` không rỗng. Hai lệnh `DELETE` xóa mỗi bảng một dòng. Sau dọn: Auth `users=9`, Customer `customer_profiles=2`; seed nguyên vẹn.

## Cách chụp minh chứng
Chụp dòng `register=201 status=ACTIVE loginTokenPresent=True` và hai số đếm sau dọn; che email/phone/token nếu editor có hiển thị. Gợi ý `TC09-register-active.png`.
