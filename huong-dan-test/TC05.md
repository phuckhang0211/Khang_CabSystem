# TC05 — Compose và 17 container

## Mục tiêu
Kiểm tra Gateway, bảy service, bảy PostgreSQL, Redis và RabbitMQ cùng hoạt động.

## Điều kiện trước
Mở PowerShell tại thư mục gốc; đã chạy `docker compose up -d --build` ở chế độ thường và chờ healthcheck xanh. Không cần token.

## Các bước
```powershell
docker compose ps
docker compose ps --format "table {{.Name}}\t{{.Status}}"
$containers = @(docker compose ps --format json | ForEach-Object { $_ | ConvertFrom-Json })
"containers=$($containers.Count) healthy=$(@($containers | Where-Object { $_.Health -eq 'healthy' }).Count)"
```

## Kết quả mong đợi
Có đúng 17 container và 17 trạng thái healthy: `gateway`, bảy `*-service`, bảy `*-db`, `redis`, `rabbitmq`. Chế độ thường chỉ publish host port `3000` và `15672`; không có port host cho DB, Redis hoặc gRPC.

## Cách chụp minh chứng
Chụp bảng `docker compose ps` và dòng tổng `containers=17 healthy=17`; gợi ý `TC05-17-container.png`.
