# TC03 — Nhiệm vụ của Gateway

## Mục tiêu
Minh họa Gateway định tuyến REST, tạo correlation ID, xác thực JWT, phân quyền RBAC, giới hạn tần suất và chuyển request sang gRPC.

## Điều kiện trước
Compose thường đã chạy, 17 container healthy và đã seed. PowerShell ở thư mục gốc. Tài khoản Customer 1 seed: `customer1@example.test` / `Customer@123`. Giới hạn login mặc định 5 lần/phút/IP; không login lặp. Nếu vừa chạy Postman TC29, chờ ít nhất 65 giây.

## Các bước
```powershell
$out = Join-Path $env:TEMP 'tc03-response.json'
$code = curl.exe -s -o $out -w '%{http_code}' http://localhost:3000/api/v1/customers/me
"no-token=$code error=$((Get-Content $out -Raw | ConvertFrom-Json).error.code)"
$login = @{ identifier = 'customer1@example.test'; password = 'Customer@123' } | ConvertTo-Json -Compress
$token = (Invoke-RestMethod -Method Post -Uri 'http://localhost:3000/api/v1/auth/login' -ContentType 'application/json' -Body $login).data.accessToken
$code = curl.exe -s -o $out -w '%{http_code}' -H "Authorization: Bearer $token" http://localhost:3000/api/v1/admin/driver-applications
"wrong-role=$code error=$((Get-Content $out -Raw | ConvertFrom-Json).error.code)"
$health = Invoke-WebRequest -UseBasicParsing -Uri 'http://localhost:3000/api/v1/health'
"health=$($health.StatusCode) correlation=$($health.Headers['x-correlation-id'])"
Remove-Item -LiteralPath $out
```
Đối chiếu `docs/SPEC.md` §9: middleware theo thứ tự correlation ID → helmet → JSON → rate limit → JWT → RBAC → validate → controller; controller chuyển REST sang RPC gRPC và map lỗi về JSON. Redis giữ bộ đếm rate limit.

## Kết quả mong đợi
Thiếu JWT trả `401 INVALID_TOKEN`; Customer gọi route Admin trả `403 FORBIDDEN`. Health trả 200 và có header `x-correlation-id`. Gateway là cổng REST duy nhất từ host; service gRPC không publish cổng.

## Cách chụp minh chứng
Chụp ba dòng `no-token`, `wrong-role`, `health` trong terminal; không chụp giá trị `$token`. Gợi ý `TC03-gateway-jwt-rbac.png`.
