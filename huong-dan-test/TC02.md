# TC02 — `.gitignore` và `.env`

## Mục tiêu
Chứng minh `.env` cục bộ bị Git bỏ qua và `.env.example` được theo dõi làm mẫu cấu hình.

## Điều kiện trước
Mở PowerShell tại thư mục gốc repo; `.env` đã được tạo local. Không hiển thị hoặc chụp giá trị của `.env`.

## Các bước
```powershell
git check-ignore -v .env
git ls-files | Select-String '\.env'
Get-Content .env.example | Select-String '^(GATEWAY_PORT|AUTH_DB_NAME|RATE_LIMIT_LOGIN_PER_MIN)='
```
Mở `.env.example` trong editor để xem các nhóm biến mẫu; không mở `.env` trên màn hình chụp.

## Kết quả mong đợi
Lệnh đầu cho biết quy tắc `.gitignore` bỏ qua `.env`; Git chỉ theo dõi `.env.example`. File mẫu có port Gateway, tên Auth DB và giới hạn login mặc định 5/phút, không chứa khóa bí mật của máy local.

## Cách chụp minh chứng
Chụp ba kết quả terminal và tab `.env.example` chỉ ở các dòng mẫu không nhạy cảm; gợi ý `TC02-env-gitignore.png`.
