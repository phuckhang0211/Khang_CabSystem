# TC08 — Mọi request đi qua Gateway

## Mục tiêu
Chứng minh host chỉ gọi REST qua Gateway; gRPC luôn nội bộ, DB/Redis chỉ mở host port khi bật debug overlay.

## Điều kiện trước
Mở PowerShell tại thư mục gốc; Compose thường có 17 container healthy và đã seed. Không cần token. Bài này sẽ chuyển sang debug rồi trả về chế độ thường, giữ nguyên volume.

## Các bước
```powershell
function Get-OpenPorts([int[]]$ports) {
    foreach ($port in $ports) {
        if ((Test-NetConnection localhost -Port $port -WarningAction SilentlyContinue).TcpTestSucceeded) { $port }
    }
}
$grpc = @(50051..50057)
$debugPorts = @((5433..5439) + 6379)
$all = @(3000, 15672) + $grpc + $debugPorts
$regularOpen = @(Get-OpenPorts $all)
"regular-open=$($regularOpen -join ',')"
try {
    docker compose -f docker-compose.yml -f docker-compose.debug.yml up -d | Out-Null
    $debugOpen = @(Get-OpenPorts $all)
    "debug-open=$($debugOpen -join ',')"
} finally {
    docker compose up -d | Out-Null
}
$restoredOpen = @(Get-OpenPorts $all)
"restored-open=$($restoredOpen -join ',')"
$ready = Invoke-RestMethod 'http://localhost:3000/api/v1/ready'
"ready=$($ready.status) containers=$(@(docker compose ps --format json | ForEach-Object { $_ | ConvertFrom-Json }).Count)"
```

## Kết quả mong đợi
Chế độ thường mở `3000,15672`, đóng `50051..50057`, `5433..5439`, `6379`. Debug mở thêm `5433..5439,6379`; bảy cổng gRPC vẫn đóng. Sau khi trả về thường, lại chỉ mở `3000,15672`, `/ready` là `ready` và có 17 container. `Test-NetConnection` với cổng đóng báo `TcpTestSucceeded=False`.

## Cách chụp minh chứng
Chụp ba dòng `regular-open`, `debug-open`, `restored-open` và dòng readiness; gợi ý `TC08-host-ports.png`. Không chụp cấu hình mật khẩu DB.
